# CellLab Python

Симуляция клеточного мира на Python и Pygame. Проект начался как первая учебная программа, а теперь постепенно превращается в маленькую лабораторию эволюции: клетки живут в сеточном мире, выполняют геном, фотосинтезируют, делятся, мутируют, оставляют следы и реагируют на условия среды.

## Что умеет симуляция

- Клетки имеют геном из чисел и указатель текущей команды.
- Геном управляет фотосинтезом, проверкой энергии, реакцией на температуру, обзором соседней клетки, реакцией на свет и безусловными переходами.
- Клетки делятся, мутируют и передают измененный геном потомкам.
- Часть клеток может стать хищниками.
- Органика остается после смерти клетки и может быть съедена.
- Мир смотрится сверху: органика не падает вниз.
- Есть слои среды: свет, влажность и химический след клеток.
- Давление популяции штрафует слишком плотные колонии.
- GUI показывает количество клеток, органики, цикл, температуру, время симуляции, время отрисовки, количество нарисованных объектов и FPS.

## Новый движок мира

Проект разделен на две большие части: симуляцию и отрисовку.

- `simulation.py` отвечает за шаг мира: обновление клеток, органики, счетчиков и слоев среды.
- `genome.py` содержит клетки, хищников, органику и команды генома.
- `misc/environment.py` хранит свет, влажность и химические следы.
- `pygame_init_graphic/renderer.py` рисует мир через Pygame.
- `pygame_init_graphic/gui.py` рисует панель управления и окно настроек.
- `camera/camera.py` отвечает за масштаб и перемещение камеры.
- `tests/` содержит тесты логики симуляции без запуска окна Pygame.

## Производительность

Ветка `dev_math` была посвящена ускорению текущей архитектуры без смены идеи симуляции.

Что уже сделано:

- Симуляция идет по активным объектам, а не по всей пустой сетке.
- Активные объекты разделены на `active_bots` и `active_food`, чтобы цикл меньше ветвился.
- Для быстрых проверок есть `bot_grid` и `neighbor_grid`: количество соседей читается из готовой карты.
- Математика, зависящая от температуры, высоты и света, кэшируется на цикл.
- Объекты клеток и органики используют `__slots__`, чтобы занимать меньше памяти.
- Фон мира кэшируется отдельной поверхностью.
- День и ночь рисуются легким overlay, без пересборки всего фона.
- Для `CELL_SIZE = 1` есть быстрый пиксельный путь рендера, потому что это самый тяжелый стресс-тест.

Оптимизации симуляции работают при любом размере клетки. Размер клетки `1` просто сильнее всего нагружает программу, потому что на экране одновременно может быть десятки тысяч объектов.

## Управление

- `STOP` / `PLAY` останавливает и запускает симуляцию.
- `RESTART` пересоздает мир.
- `SETTINGS` открывает настройки мира.
- В настройках можно менять размер клетки, размер генома и стартовое количество клеток.
- Клавиши `+` и `-` меняют масштаб камеры.
- Стрелки двигают камеру при увеличенном масштабе.

## Запуск

Установить зависимости:

```bash
pip install pygame
```

Запустить приложение:

```bash
python main.py
```

Запустить тесты:

```bash
python -m unittest discover -s tests
```

Если используется локальное виртуальное окружение проекта:

```bash
.venv/bin/python main.py
.venv/bin/python -m unittest discover -s tests
```

## Структура проекта

- `main.py` - точка входа.
- `simulation.py` - главный цикл логики мира.
- `genome.py` - клетки, хищники, органика и команды генома.
- `misc/vars.py` - размеры мира, глобальные счетчики, быстрые карты и кэши.
- `misc/environment.py` - свет, влажность и химические следы.
- `misc/func.py` - вспомогательные функции.
- `misc/colors.py` - цвета мира и GUI.
- `pygame_init_graphic/` - инициализация Pygame, GUI, renderer и игровой цикл.
- `camera/` - камера и масштабирование.
- `font/` - шрифт интерфейса.
- `docs/` - заметки по геному и идеям развития.
- `old_code/` - старый код, с которого все началось.
